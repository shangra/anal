# Документация модуля Auth.service.js

Данный модуль реализует функциональность аутентификации пользователей и управления правами доступа в системе. Он предоставляет набор методов для создания пользователя, изменения пароля, получения информации о пользователе, а также работы с ролями и правилами доступа.

## Основные задачи модуля:
- Аутентификация пользователя через ввод логина и пароля.
- Управление пользователями: создание нового пользователя, изменение пароля, получение информации о пользователе.
- Работа с ролями и правилами доступа: добавление правил и ролей пользователю, удаление ролей у пользователя, получение списка всех доступных пользователю правил и ролей.
- Сохранение сессии пользователя и установка его в хранилище HTTP-контекста.

## Структура модуля

### Импортируемые зависимости
- **ApiError**: Класс ошибок API, используемый для обработки исключений.
- **User**, **UserInfos**, **UserRule**, **UserRole**, **GroupUser**, **URoles**, **URules**: Модели базы данных, используемые для взаимодействия с таблицами пользователей, прав и ролей.
- **UserDto**, **UserInfoDto**, **RoleDto**, **RuleDto**: Классы DTO (Data Transfer Objects), предназначенные для передачи данных между слоями приложения.
- **defaultRules**, **defaultRoles**, **defaultGroups**: Константы, содержащие стандартные правила, роли и группы пользователей.
- **UsersServiceClass**, **UsersService**: Сервисы для работы с пользователями.
- **GlobalService**: Глобальный сервис, предоставляющий вспомогательные функции, такие как шифрование паролей.
- **Extensions**: Базовый класс расширений, от которого наследуется данный сервис.
- **UsersModel**: Модель для работы с пользователями.
- **httpContext**: Сервис для работы с контекстом HTTP-запросов.

### Методы класса AuthService

#### 1. **createUser(userData)**  
Создает нового пользователя в базе данных. Проверяет наличие существующего пользователя с тем же логином и создает новую запись, если пользователь еще не зарегистрирован. Пароль зашифровывается перед сохранением.

**Параметры:**  
- **userData**: объект с полями `login`, `password`.

**Возвращаемое значение:**  
Объект типа `UserDto`, представляющий созданного пользователя.

---

#### 2. **fullCreateUser(data)**  
Полностью создает пользователя, включая информацию о нем. Сначала вызывает метод `createUser`, затем добавляет дополнительную информацию о пользователе.

**Параметры:**  
- **data**: объект с информацией о пользователе (`login`, `password`, дополнительная информация).

**Возвращаемое значение:**  
Объект с объединенной информацией о пользователе и дополнительной информацией.

---

#### 3. **changeUserPassword(login, password)**  
Изменяет пароль пользователя по его логину. Если пользователь найден, обновляет его пароль.

**Параметры:**  
- **login**: Логин пользователя.
- **password**: Новый пароль.

**Возвращаемое значение:**  
Объект типа `UserDto`, представляющий изменённого пользователя.

---

#### 4. **changeUserPasswordByID(userId, password)**  
Изменяет пароль пользователя по его идентификатору. Аналогичен предыдущему методу, но использует ID вместо логина.

**Параметры:**  
- **userId**: Идентификатор пользователя.
- **password**: Новый пароль.

**Возвращаемое значение:**  
Объект типа `UserDto`, представляющий изменённого пользователя.

---

#### 5. **addUserPermission(userId, rules, roles, groups)**  
Добавляет права, роли и группы пользователю. По умолчанию используются стандартные значения из констант.

**Параметры:**  
- **userId**: Идентификатор пользователя.
- **rules**: Массив идентификаторов правил (опционально).
- **roles**: Массив идентификаторов ролей (опционально).
- **groups**: Массив идентификаторов групп (опционально).

---

#### 6. **addUserRule(userId, rules)**  
Добавляет правила пользователю.

**Параметры:**  
- **userId**: Идентификатор пользователя.
- **rules**: Массив идентификаторов правил.

---

#### 7. **addUserRole(userId, roles)**  
Добавляет роли пользователю.

**Параметры:**  
- **userId**: Идентификатор пользователя.
- **roles**: Массив идентификаторов ролей.

---

#### 8. **delUserRole(userId, roles)**  
Удаляет указанные роли у пользователя.

**Параметры:**  
- **userId**: Идентификатор пользователя.
- **roles**: Массив идентификаторов ролей.

---

#### 9. **addUserGroups(userId, groups)**  
Добавляет группы пользователю.

**Параметры:**  
- **userId**: Идентификатор пользователя.
- **groups**: Массив идентификаторов групп.

---

#### 10. **getAllUserRule(id)**  
Получает полный список правил, применяемых к пользователю, включая те, которые назначены напрямую и через роли.

**Параметры:**  
- **id**: Идентификатор пользователя.

**Возвращаемое значение:**  
Массив объектов, содержащих информацию о правилах и ролях.

---

#### 11. **getUserRoleWithRules(id)**  
Получает список ролей пользователя вместе со связанными правилами.

**Параметры:**  
- **id**: Идентификатор пользователя.

**Возвращаемое значение:**  
Список объектов, каждый из которых содержит роль и связанные с ней правила.

---

#### 12. **getUserRule(id)**  
Получает непосредственно присвоенные пользователю правила.

**Параметры:**  
- **id**: Идентификатор пользователя.

**Возвращаемое значение:**  
Массив объектов, представляющих правила пользователя.

---

#### 13. **getUserRole(id)**  
Получает список ролей пользователя.

**Параметры:**  
- **id**: Идентификатор пользователя.

**Возвращаемое значение:**  
Массив объектов, представляющих роли пользователя.

---

#### 14. **getUserRoleAndGroups(id)**  
Получает список ролей и групп пользователя.

**Параметры:**  
- **id**: Идентификатор пользователя.

**Возвращаемое значение:**  
Два массива: один — с ролями, другой — с группами.

---

#### 15. **addUserInfo(id, data)**  
Добавляет или обновляет информацию о пользователе.

**Параметры:**  
- **id**: Идентификатор пользователя.
- **data**: Дополнительные данные о пользователе.

**Возвращаемое значение:**  
Объект типа `UserInfoDto`, содержащий обновленную информацию о пользователе.

---

#### 16. **getUserInfo(id)**  
Получает информацию о пользователе.

**Параметры:**  
- **id**: Идентификатор пользователя.

**Возвращаемое значение:**  
Объект типа `UserInfoDto`, содержащий информацию о пользователе.

---

#### 17. **saveSessionId(user, sessionId)**  
Сохраняет сессию пользователя в базу данных.

**Параметры:**  
- **user**: Объект пользователя.
- **sessionId**: Идентификатор сессии.

**Возвращаемое значение:**  
Записанный объект пользователя.

---

#### 18. **login(data)**  
Осуществляет процесс входа пользователя в систему. Проверяет введённые логин и пароль, возвращает объект пользователя.

**Параметры:**  
- **data**: Объект с полями `login`, `password`.

**Возвращаемое значение:**  
Объект типа `UserDto`, представляющий вошедшего пользователя.

---

#### 19. **setUserInSession(userData)**  
Устанавливает пользователя в текущий сеанс запроса.

**Параметры:**  
- **userData**: Объект пользователя.

**Возвращаемое значение:**  
Объект пользователя с дополненными данными.

---

#### 20. **setUserInStore(store, user)**  
Сохраняет пользователя в хранилище HTTP-сессии.

**Параметры:**  
- **store**: Хранилище HTTP-сессий.
- **user**: Объект пользователя.

**Возвращаемое значение:**  
Объект пользователя.

---

#### 21. **setUserLastAccessDate(id)**  
Обновляет дату последнего доступа пользователя.

**Параметры:**  
- **id**: Идентификатор пользователя.

**Возвращаемое значение:**  
Объект типа `UserDto`, представляющий обновленного пользователя.

---

#### 22. **afterLogin(userData)**  
Хук, вызываемый после успешной авторизации пользователя. Может использоваться для дополнительных действий после входа.

**Параметры:**  
- **userData**: Объект пользователя.

**Возвращаемое значение:**  
Объект пользователя.

## Использование модуля

Модуль предназначен для использования внутри других сервисов и контроллеров. Например, он может быть использован в контроллере аутентификации для реализации процесса регистрации и входа пользователя.

Пример использования метода `login`:

```javascript
const authService = new AuthService();
authService.login({ login: 'admin', password: 'password' })
    .then(user => console.log(`Пользователь ${user.login} успешно вошел`))
    .catch(error => console.error(error.message));
```

Таким образом, этот модуль обеспечивает базовую инфраструктуру для работы с пользователями и управлением доступом в приложении.

# Документация модуля Groups

Данный модуль предоставляет функциональность работы с группами пользователей. Он включает в себя основные CRUD операции над группами, а также проверку существования групп перед выполнением каких-либо действий.

## Структура модулей

### services/Groups.service.js
Этот файл содержит класс `GroupsService`, который реализует основную логику взаимодействия с моделями групп (`GroupModel`) и обеспечивает обработку ошибок через исключение `ApiError`.

### Модели
Используется модель `GroupModel`, которая отвечает за взаимодействие с базой данных и получение данных о группах.

### DTO
Используется DTO-класс `GroupDto`, который преобразует сырые данные из базы данных в формат, удобный для использования приложением.

---

## Методы класса `GroupsService`

### `async getGroups(ids, options = {})`
Возвращает массив объектов групп по указанным идентификаторам. Принимает два аргумента:
- **ids** — массив идентификаторов групп.
- **options** — дополнительные параметры запроса (опциональные).

#### Возвращаемое значение:
Массив объектов типа `GroupDto`.

---

### `async getAllGroups(options = {})`
Возвращает список всех существующих групп. Принимает один аргумент:
- **options** — дополнительные параметры запроса (опциональные).

#### Возвращаемое значение:
Массив объектов типа `GroupDto`.

---

### `async getGroup(id)`
Возвращает одну группу по её идентификатору. Принимает один аргумент:
- **id** — идентификатор группы.

#### Возвращаемое значение:
Объект типа `GroupDto`.

---

### `async checkGroup(id)`
Проверяет существование группы по указанному идентификатору. Если группа не найдена, выбрасывает ошибку `BadRequest`. Принимает один аргумент:
- **id** — идентификатор группы.

#### Возможное исключение:
- `ApiError.BadRequest('Такой группы не существует')` — если группа не найдена.

---

## Пример использования

```javascript
const GroupsService = require('./services/Groups.service');
const groupsService = new GroupsService();

(async function main() {
    try {
        const allGroups = await groupsService.getAllGroups();
        console.log(allGroups); // вывод списка всех групп

        const specificGroup = await groupsService.getGroup(5);
        console.log(specificGroup); // вывод конкретной группы

        await groupsService.checkGroup(6); // проверка наличия группы
    } catch (error) {
        console.error(error.message); // обработка ошибки
    }
})();
```

---

Таким образом, данный модуль предоставляет полный набор методов для управления группами пользователей, включая получение отдельных записей, списков и проверки существования групп.

# Документация модуля Users

Данный модуль предназначен для управления пользователями, ролями, группами и правилами доступа в системе. Он предоставляет широкий набор методов для работы с этими сущностями, включая создание, редактирование, удаление и получение информации о них.

## Структура Модуля

### services/Users.service.js
Основной сервисный класс, содержащий всю логику взаимодействия с моделями и другими службами. В нем реализованы методы для выполнения различных операций над пользователями, ролями, группами и правами доступа.

## Основные Методы

### Пользователи (`Users`)

#### Получение Пользователей
- **getUsers**: Возвращает список пользователей по указанным идентификаторам.
- **getAllUsers**: Возвращает всех пользователей с возможностью фильтрации.
- **searchUserByAttributeValue**: Поиск пользователей по значению атрибута.
- **searchUsersByFio**: Поиск пользователей по ФИО.
- **getUser**: Возвращает информацию о конкретном пользователе.
- **getUserMeta**: Возвращает метаданные пользователя.

#### Управление Пользователями
- **editUser**: Обновляет информацию о пользователе.
- **fullUpdateUser**: Полное обновление информации о пользователе.
- **deleteUser**: Удаляет пользователя из базы данных.
- **restoreUser**: Восстанавливает ранее удалённого пользователя.
- **blockUser**: Блокирует доступ пользователя.
- **unblockUser**: Разблокирует заблокированного пользователя.

#### Аттрибуты Пользователей
- **setUserAttribute**: Устанавливает значение атрибута пользователю.
- **getUserAttribute**: Получает значение атрибута пользователя.
- **checkAttribute**: Проверяет существование атрибута.
- **getAllAttributes**: Возвращает полный список атрибутов.
- **getAllowedAttributes**: Возвращает разрешённые атрибуты (может быть переопределён).

### Роли (`Roles`)

#### Работа с Ролями
- **createRole**: Создаёт новую роль.
- **editRole**: Редактирует существующую роль.
- **getRole**: Возвращает конкретную роль.
- **getRoleByName**: Находит роль по её названию.
- **getRoleByCode**: Находит роль по её кодовому обозначению.
- **addRoleRule**: Добавляет правило к роли.
- **getRoleRule**: Возвращает правила назначенные данной роли.
- **getRoleUsers**: Возвращает пользователей принадлежащих данной роли.

### Группы (`Groups`)

#### Управление Группами
- **createGroup**: Создаёт новую группу.
- **editGroup**: Редактирует существующий группу.
- **delGroup**: Удаляет группу.
- **getGroup**: Возвращает конкретную группу.
- **getOpenGroups**: Возвращает открытые группы.
- **getGroupUsers**: Возвращает пользователей конкретной группы.

### Правила Доступа (`Rules`)

#### Права Доступа
- **getRules**: Возвращает конкретные правила по идентификатору.
- **getAllRules**: Возвращает все доступные правила.
- **addUserRule**: Назначает право определенному пользователю.
- **getRuleUsers**: Возвращает пользователей которым назначено данное право.

### Матрицы Связей

Методы возвращают матрицы связей между различными объектами:
- **getRoleRuleMatrix**: Матрица ролей-правил.
- **getUserRoleMatrix**: Матрица пользователей-ролей.
- **getUserGroupMatrix**: Матрица пользователей-групп.
- **getUserRuleMatrix**: Матрица пользователей-правил.

## Дополнительные Функции

- **upload**: Загрузка аватара пользователя через глобальный сервис загрузки.
- **checkUser**, **checkRole**, **checkGroup**, **checkRule**: Вспомогательные проверки существования объектов перед выполнением действий.

## Примеры использования

### Пример поиска пользователя по его ID:
```javascript
const UsersService = require('./services/Users.service');
const service = new UsersService();
service.getUser(1); // возвращает информацию о пользователе с ID=1
```

### Пример добавления новой роли:
```javascript
const UsersService = require('./services/Users.service');
const service = new UsersService();
service.createRole({ name: 'admin' }); // создаёт новую роль с названием admin
```

### Пример назначения права пользователю:
```javascript
const UsersService = require('./services/Users.service');
const service = new UsersService();
service.addUserRule(1, 5); // назначает право с ID=5 пользователю с ID=1
```

---

Этот модуль обеспечивает гибкость и масштабируемость в управлении пользователями и связанными с ними ресурсами, позволяя легко добавлять новые сущности и настраивать систему под специфические требования приложения.
