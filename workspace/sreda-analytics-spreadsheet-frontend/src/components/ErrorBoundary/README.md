## 1. Применение и функционал <a id="component-purpose" name="component-purpose"></a>

Компонент **ErrorBoundary** предназначен для отлова ошибок в компонентах системы и предотвращения падения всего приложения. <br />
Это позволяет как корректно и понятно для пользователя отобразить ошибку компонента, так и позволить разработчику даже не заходя в логи приложения <br />
обнаружить ошибку и устранить ее причины.

## 2. Пояснения к реализации <a id="implementation-explanation" name="implementation-explanation"></a>

Компонент содержит два метода для обработки ошибок:
1) `componentDidCatch` - метод, получающий информацию об ошибке и позволяющий настроить логирование;
2) `getDerivedStateFromError` - извлечение нового state компонента, при изменении которого <br />
произойдет перерендер и может быть отображен запасной UI (props.fallbackUI - функция/ReactNode).

## 3. Особенности применения <a id="apply-features" name="apply-features"></a>

Для использования компонента необходимо обернуть нужный компонент в ```<ErrorBoundary></ErrorBoundary>```. <br />
В случае надобности компонент принимает пропс `fallbackUI`, который будет отрендерен вместо дефолтного отображения ошибки.
