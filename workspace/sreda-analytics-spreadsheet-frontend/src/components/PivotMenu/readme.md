## 1. Применение и функционал <a id="component-purpose" name="component-purpose"></a>

Компонент **PivotMenu** предназначен для установки настроек схемы (слои, строки, столбцы, фильтры).
Представляет собой правый Drawer, который появляется при нажатии на иконку бургера на странице куба или отчета (MenuIcon).
Настройки передаются в качестве пропсов и хранятся в schemaSettings в PivotSchema.
Сейчас могут использоваться 2 версии компонента - при изменениях нужно менять и в v1, и в v2.
