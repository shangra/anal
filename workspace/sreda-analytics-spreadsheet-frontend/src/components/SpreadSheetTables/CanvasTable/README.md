## 1. Применение и функционал <a id="component-purpose" name="component-purpose"></a>

Компонент **Spreadsheet** предназначен для отображение данных в табличном виде </br>

## 2. Пояснения к реализации <a id="implementation-explanation" name="implementation-explanation"></a>

**В компоненте реализована поддержка экранов с различной плотностью пикселей.** </br>
В коде есть расчеты, в которых встречается переменная DPR, которая показывает то насколько увеличенна плотность пикселей на экране пользователя, например на macbook'ах она равна двум.
DOM-модель уже адаптирована под разную плотность, в отличие от html canvas, поэтому мы в коде задаем, width и height DOM-элемента, той, что получаем в props'ах, а внутренние размеры canvas'а умножаем на DPR. Отсюда следует, что например на экранах с плотность пикселей равное 2, внутренние размеры отрисовываемых объектов на canvas будут в 2 раза больше. </br>
Если этого не делать, то все что будет отрисовано на canvas, будет иметь плохое качество.

---

Скролл и зум по таблице реализовать по паттерну ZoomUI
ZoomUI паттерны состоит из 4-ех основных элементов:

1. **Canvas** - Бесконечная доска (ограниченна границами таблице)
2. **Camera** - Точка, относительно которой двигается Canvas
3. **Screen** - То, что видит пользователь, x и y всегда будут равны 0, а width и height - установленных в пропсах значениях ширины и высоты
4. **Viewport** - часть Canvas'а, которая видна на экране(Screen), x и y изменяемы взависимости от положения и зума камеры, width = (x + width) \* DPR, height = (y + height) \* DPR

Есть набор функций, которые помогают при работе с ZoomUI (находятся в [файле](utils/index.ts)):

1. **screenToCanvas()** - переводит точку на экране в точку на canvas, основываясь на текущем положение и зумом камеры
2. **canvasToScreen()** - переводит точку на canvas в точку на экране, основываясь на текущем положение и зумом камеры
3. **getViewport()** - получение Viewport'а основываюсь, на значениях camera
4. **panCamera()** - получение нового положения камеры, основываясь на новых значениях скрола
5. **zoomCamera** получение нового зума камеры, основываясь на новых значениях зума

Подробно о данном паттерне рассказано в данной [статье](https://www.steveruiz.me/posts/zoom-ui) </br>

## 3. Особенности применения <a id="apply-features" name="apply-features"></a>

Пропсы

1. width - ширина компонента
2. height - высота компонента
3. columnsAmount - количество колонок
4. rowsAmount - количество рядов
5. joinedCellsRanges - объединенные ячейки
6. columnsMetadata - массив размеров каждой колонки;
7. rowsMetadata - массив размеров каждого ряда
8. onRowHeaderMouseEnter - событие входа курсора мыши в шапку рядов
9. onRowHeaderMouseMove - событие движения курсора мыши по шапке рядов
10. onRowHeaderMouseLeave - событие выхода курсора мыши из шапки рядов
12. onColumnsHeaderMouseMove - событие движения курсора мыши по шапке колонок
14. onColumnsHeaderCellEnter - событие входа курсора мыши в ячейку шапку колонки
15. onColumnsHeaderCellMouseMove - событие движения курсора мыши по ячейки шапки колонки
16. onColumnsHeaderCellLeave - событие выхода курсора мыши из ячейки шапки колонки
17. onRowsHeaderCellEnter - событие входа курсора мыши в ячейку шапку ряда
18. onRowsHeaderCellMouseMove - событие движения курсора мыши по ячейки шапки ряда
19. onRowsHeaderCellLeave - событие выхода курсора мыши из ячейки шапки ряда
