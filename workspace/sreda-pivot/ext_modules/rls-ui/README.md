## Модуль управления разрешениями (RlsUI)

Модуль предназначен для централизованного управления правами доступа пользователей, групп, ролей и правилами на уровне сущностей базы данных.

### Назначение модуля

Данный модуль обеспечивает возможность гибкого контроля разрешений на чтение, изменение и удаление объектов в базе данных. Позволяет получать информацию о текущих правах доступа и управлять ими через единый интерфейс.

---

## Основные компоненты модуля

### Сервис управления разрешениями (RlsUIService)

Сервис реализует основные методы для взаимодействия с системой прав доступа. Все методы являются асинхронными и возвращают промисы.

#### Методы сервиса

1. **getAllPermissions(table_name, table_id, queryType)**  
   Возвращает полную информацию обо всех типах разрешений для заданной сущности.
   
   Параметры:
   - `table_name`: имя таблицы
   - `table_id`: идентификатор строки
   - `queryType`: тип запроса
   
   Возврат:
   ```typescript
   {
      users: any; // пользователи с разрешениями
      roles: any; // роли с разрешениями
      rules: any; // правила с разрешениями
      groups: any; // группы с разрешениями
   }
   ```

2. **getAdmittedUsers(table_name, table_id, type)**  
   Возвращает список пользователей, имеющих разрешение на указанную сущность.
   
   Параметры:
   - `table_name`: имя таблицы
   - `table_id`: идентификатор строки
   - `type`: тип разрешения
   
   Возврат: массив пользователей с разрешением

3. **getAdmittedRoles(table_name, table_id, type)**  
   Возвращает список ролей, имеющих разрешение на указанную сущность.
   
   Параметры аналогичны методу `getAdmittedUsers`.
   
   Возврат: массив ролей с разрешением

4. **getAdmittedRules(table_name, table_id, type)**  
   Возвращает список правил, применимых к указанной сущности.
   
   Параметры аналогичны предыдущим методам.
   
   Возврат: массив правил с разрешением

5. **getAdmittedGroups(table_name, table_id, type)**  
   Возвращает список групп, имеющих разрешение на указанную сущность.
   
   Параметры аналогичны другим методам.
   
   Возврат: массив групп с разрешением

6. **getPermissionsMeta(table_name, table_id, owner, type)**  
   Возвращает метаданные разрешений для указанной сущности.
   
   Параметры:
   - `table_name`: имя таблицы
   - `table_id`: идентификатор строки
   - `owner`: владелец сущности
   - `type`: тип разрешения
   
   Возврат: метаданные разрешений

7. **getEntityAllTypePermissions(table_name, table_id, owner)**  
   Возвращает все типы разрешений для указанной сущности.
   
   Параметры:
   - `table_name`: имя таблицы
   - `table_id`: идентификатор строки
   - `owner`: владелец сущности
   
   Возврат: массив всех типов разрешений

## Использование модуля

Для использования функционала модуля необходимо создать экземпляр класса `RlsUIService` и вызывать необходимые методы для получения информации о разрешениях или управления ими.

Пример использования:
```javascript
const RlsUIService = require('./services/RlsUI.service');
const rlsService = new RlsUIService();

async function checkUserAccess(userId, entityTableName, entityId) {
  try {
    const permissions = await rlsService.getAllPermissions(entityTableName, entityId, 'read');
    
    if (permissions.users.includes(userId)) {
      console.log(`Пользователь ${userId} имеет доступ`);
    } else {
      console.log(`Пользователь ${userId} не имеет доступа`);
    }
  } catch (error) {
    console.error('Ошибка при проверке доступа:', error);
  }
}
```

# Документация модуля RLS UI Service

## Описание модуля

Модуль **RLS UI Service** предназначен для управления разрешениями доступа пользователей, групп, ролей и правил к различным сущностям системы. Модуль обеспечивает получение метаданных разрешений для отображения в интерфейсе администрирования прав доступа.

---

## Основные Функции

### 1. Получение всех разрешений для таблицы

Метод возвращает полный список разрешений для заданной таблицы и идентификатора строки.

```javascript
async getAllPermissions(table_name, table_id, queryType)
```

Параметры:
- `table_name`: Имя таблицы
- `table_id`: Идентификатор строки в таблице
- `queryType`: Тип запрашиваемых разрешений ('read' по умолчанию)

Возвращаемое значение:
Объект с полями:
- `users`: Список допущенных пользователей
- `roles`: Список допустимых ролей
- `rules`: Список применяемых правил
- `groups`: Список разрешённых групп

---

### 2. Получение допущенных пользователей

Метод возвращает список пользователей, имеющих разрешение на указанную таблицу и строку.

```javascript
async getAdmittedUsers(table_name, table_id, type)
```

Параметры:
- `table_name`: Имя таблицы
- `table_id`: Идентификатор строки в таблице
- `type`: Тип разрешения (по умолчанию совпадает с типом запроса)

Возвращаемое значение:
Список объектов пользователей.

---

### 3. Получение допущенных ролей

Метод возвращает список ролей, имеющих разрешение на указанную таблицу и строку.

```javascript
async getAdmittedRoles(table_name, table_id, type)
```

Параметры аналогичны методу `getAdmittedUsers`.

Возвращаемое значение:
Список объектов ролей.

---

### 4. Получение допущенных правил

Метод возвращает список правил, применимых к указанной таблице и строке.

```javascript
async getAdmittedRules(table_name, table_id, type)
```

Параметры аналогичны методу `getAdmittedUsers`.

Возвращаемое значение:
Список объектов правил.

---

### 5. Получение допущенных групп

Метод возвращает список групп, имеющих разрешение на указанную таблицу и строку.

```javascript
async getAdmittedGroups(table_name, table_id, type)
```

Параметры аналогичны методу `getAdmittedUsers`.

Возвращаемое значение:
Список объектов групп.

---

### 6. Получение метаданных разрешений

Метод возвращает специфичные метаданные разрешений для указанного типа владельцев.

```javascript
async getPermissionsMeta(table_name, table_id, owner, type)
```

Параметры:
- `table_name`: Имя таблицы
- `table_id`: Идентификатор строки в таблице
- `owner`: Тип владельца ('users', 'roles', 'rules', 'groups')
- `type`: Тип разрешения

Возвращаемое значение:
Специфичный список объектов в зависимости от типа владельца.

---

### 7. Получение всех типов разрешений для сущности

Метод собирает информацию обо всех типах разрешений для указанной сущности.

```javascript
async getEntityAllTypePermissions(table_name, table_id, owner)
```

Параметры:
- `table_name`: Имя таблицы
- `table_id`: Идентификатор строки в таблице
- `owner`: Тип владельца ('users', 'roles', 'rules', 'groups')

Возвращаемое значение:
Список объектов с полем `access`, содержащим массив всех типов разрешений для каждого элемента.

---

## Обработка ошибок

Модуль использует класс исключений `ApiError` для обработки некорректных параметров. Например, при передаче неверного значения параметра `owner` выбрасывается исключение `BadRequest`.

---

## Интеграция сервисов

Модуль интегрируется с другими сервисами ядра через классы:
- `RlsCoreService`: Основной сервис управления правами уровня записей
- `UsersService`: Сервис управления пользователями
- `GroupsService`: Сервис управления группами

Эти сервисы используются для получения дополнительной информации о владельцах разрешений.

---

## Заключение

Модуль **RLS UI Service** представляет собой мощный инструмент для централизованного управления и предоставления информации о правах доступа различных субъектов системы к конкретным таблицам и записям. Его гибкая архитектура позволяет легко расширять функциональность и адаптироваться под изменяющиеся требования системы контроля доступа.
