## New EXTENDED Component: meta-new-cube-page

Добавьте в системные настройки или env новый параметр "OLAP_PARENT"

В нем описывается папка для размещения OLAP кубов, шаблон который будет использоваться и имя параметра, в котором будет указан ID куба   
```js
{
    "parent": "1d9d06a8-ea67-42a2-88b3-fa73300d931f", 
    "template": "a55d0c71-8441-4215-b544-553ac558ca33",
    "paramName": "cubeId"
}
```

Добавьте в системные настройки или env новый параметр "REPORTS_PARENT"

В нем описывается папка для размещения отчетов, шаблон который будет использоваться и имя параметра, в котором будет указан ID куба

```js
{
    "parent": "1d9d06a8-ea67-42a2-88b3-fa73300d931f",
    "template": "90186efa-8b4f-482a-9319-7ad195b9bfe0",
    "paramName": "reportId"
}
```
