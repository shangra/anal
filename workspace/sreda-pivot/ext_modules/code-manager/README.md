# Документация модуля Code Service

Данный модуль предназначен для управления и исполнения кода через API-интерфейс. Модуль включает в себя функциональность для получения настроек, создания, обновления, удаления объектов, запуска пользовательского кода и обработки консольных сообщений.

---

## Структура модуля

Модуль состоит из следующих компонентов:

1. **Модель** (`code.model.js`)
   - Описывает структуру данных, используемых модулем.
   
2. **DTO (Data Transfer Object)** (`code.dto.js`)
   - Определяет передачу данных между слоями приложения.

3. **Глобальная служба** (`Global.service.js`)
   - Предоставляет общие сервисы для всего приложения.

4. **Сервис уровня приложений** (`Application.services.js`)
   - Обеспечивает взаимодействие с приложением.

5. **Основной сервис** (`code.service.js`)
   - Реализует основную логику взаимодействия с моделью и внешними компонентами.

---

## Основные методы сервиса

### 1. Управление объектами

#### a) Получение всех настроек
```javascript
async getAllSettings()
```
Возвращает все настройки, связанные с объектом.

#### b) Получение дочерних элементов
```javascript
async getChildren(id)
```
Параметры:
- `id`: Идентификатор родительского элемента.

Возвращает массив дочерних элементов указанного родителя.

#### c) Получение главного объекта
```javascript
async getMain(id)
```
Параметры:
- `id`: Идентификатор объекта.

Возвращает основной объект по указанному идентификатору.

#### d) Получение объекта с деталями
```javascript
async get(id, options)
```
Параметры:
- `id`: Идентификатор объекта.
- `options`: Дополнительные параметры запроса.

Возвращает объект с информацией о родителе и дочерних элементах.

#### e) Создание нового объекта
```javascript
async post(body)
```
Параметры:
- `body`: Данные нового объекта.

Создает новый объект на основе переданных данных.

#### f) Копирование объекта
```javascript
async copy(body)
```
Параметры:
- `body`: Данные копируемого объекта.

Копирует существующий объект с возможностью изменения имени.

#### g) Обновление объекта
```javascript
async put(id, body)
```
Параметры:
- `id`: Идентификатор обновляемого объекта.
- `body`: Новые данные объекта.

Обновляет существующий объект новыми значениями.

#### h) Удаление объекта
```javascript
async del(id)
```
Параметры:
- `id`: Идентификатор удаляемого объекта.

Удаляет указанный объект.

---

### 2. Выполнение кода

#### a) Запуск пользовательского кода
```javascript
async runCode(code, params, options)
```
Параметры:
- `code`: Код для выполнения.
- `params`: Параметры, передаваемые в исполняемый код.
- `options`: Дополнительные опции выполнения.

Выполняет предоставленный код в изолированном контексте с заданными параметрами и опциями.

#### b) Логирование консоли
```javascript
async consoleLog(accumulator, type, args)
```
Параметры:
- `accumulator`: Накопитель сообщений.
- `type`: Тип сообщения ('log', 'error', 'warning').
- `args`: Аргументы для вывода.

Логирует сообщения в соответствующий тип накопителя.

#### c) Полное выполнение сценария
```javascript
async run(id, inputParams)
```
Параметры:
- `id`: Идентификатор объекта с кодом.
- `inputParams`: Входные параметры для выполнения.

Полностью обрабатывает сценарий: получает код объекта, настраивает окружение, выполняет код и собирает результаты логирования.

## Зависимости

Модуль зависит от следующих внешних библиотек и сервисов:

- `Model`: Модель данных.
- `Dto`: Класс передачи данных.
- `GlobalService`: Глобальная служба приложения.
- `Application`: Сервис уровня приложений.
- `lite-pattern`: Библиотека паттернов.
- `vm`: Виртуальная машина Node.js для безопасного выполнения кода.

---

## Безопасность

Важно отметить, что метод `runCode()` создает виртуальное окружение для выполнения пользовательского кода. Это обеспечивает безопасность путем изоляции выполняемого кода от основных ресурсов системы. Однако рекомендуется тщательно контролировать использование метода `require` в параметрах выполнения, чтобы избежать возможных уязвимостей.
