# Документация модуля Forms

## Описание модуля

Модуль **Forms** предназначен для управления формами в системе. Он обеспечивает создание, чтение, обновление и удаление форм, а также загрузку шаблонов форм и выполнение скриптов связанных с ними. Модуль интегрируется с другими компонентами системы через сервисы метаданных и страниц.

---

## Структура модуля

Модуль состоит из одного класса `FormsService`, наследующего функциональность от базового класса `DefaultMetaObject`. Класс реализует основные методы CRUD для работы с формами.

---

## Основные методы

### `form(id)`
Возвращает конфигурацию формы для отображения в интерфейсе.

#### Параметры:
- `id`: уникальный идентификатор формы

#### Возвращаемое значение:
Объект конфигурации формы с вкладками и элементами ввода.

---

### `create(body)`
Создает новую форму.

#### Параметры:
- `body`: объект с данными новой формы

#### Пример использования:
```javascript
await formsService.create({
    name: "Новая форма",
    settings: {...}
});
```

---

### `read(id, options = {})`
Читает информацию о форме и возвращает рендерированную страницу.

#### Параметры:
- `id`: идентификатор формы
- `options`: дополнительные параметры чтения (необязательно)

#### Процесс обработки:
1. Загружает метаданные формы
2. Определяет шаблон формы
3. Загружает шаблон формы и связанный скрипт
4. Рендерит страницу с формой

---

### `update(id, body)`
Обновляет существующую форму.

#### Параметры:
- `id`: идентификатор формы
- `body`: обновленные данные формы

#### Пример использования:
```javascript
await formsService.update("123", {
    name: "Измененное название",
    settings: {...}
});
```

---

### `delete(id)`
Удаляет форму.

#### Параметры:
- `id`: идентификатор формы

---

### Вспомогательные методы

#### `_getElementInputs(fields)`
Извлекает имена полей ввода из массива полей сущности.

#### `_getElementTabularPart(tabularParts)`
Извлекает имена табличных частей из массива табличных частей сущности.

---

## Внутренняя логика загрузки шаблонов

Метод `#loadFormTemplate(formGuid, entityMeta)` загружает шаблон формы и выполняет следующую логику:

1. Проверяет наличие связанного шаблона формы
2. Если шаблон найден - загружает его данные
3. Иначе формирует шаблон на основе кода формы и метаданных сущности
4. Создает объявления переменных для полей и табличных частей
5. Объединяет эти объявления с клиентом-кодом формы

---

## Интеграция с системой

Модуль интегрируется с другими сервисами:
- `MetadataService` - для работы с метаданными сущностей
- `PagesUiService` - для рендера страниц
- `TemplatesService` - для работы с шаблонами

---

## Особенности реализации

1. Использует асинхронную обработку для всех основных методов
2. Поддерживает кастомизацию форм через привязку к шаблонам
3. Генерирует динамический клиентский код на основе метаданных
4. Обеспечивает централизованное управление формами через единый интерфейс

---

## Примечания

- Методы создания, обновления и удаления пока реализованы только с выводом в консоль
- Метод `read()` является наиболее сложным и ответственным за основную логику рендера форм
- Для полноценной интеграции требуются настройки маршрутов и контроллеров в архитектуре проекта
