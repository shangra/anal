# Документация модуля ConnectorsService

## Описание модуля

Модуль **ConnectorsService** предназначен для управления соединениями с различными источниками данных. Он обеспечивает создание, обновление, удаление и тестирование соединений, а также шифрование паролей перед сохранением настроек соединения.

## Основные Функции

### Методы класса ConnectorsService

#### Конструктор
Создает экземпляр класса ConnectorsService, наследуемого от DefaultMetaObject. Устанавливает уникальный ID компонента и имя компонента.

```javascript
constructor()
```

---

### Формирование формы настройки соединения

Метод возвращает форму конфигурации соединения с набором полей ввода для основных параметров подключения (диалект, сервер, порт, база данных, схема, пользователь, пароль и т.д.), а также кнопки тестирования соединения.

```javascript
async form(id)
```
Параметры:
- `id`: Идентификатор существующего соединения (опционально)

Возвращаемое значение:
- `{form, buttons}`: Объект с формой конфигурации и кнопкой тестирования

---

### Шифрование пароля

Метод шифрует пароль перед сохранением в настройках соединения.

```javascript
async crypto(text)
```
Параметры:
- `text`: Текстовый пароль для шифрования

Возвращаемое значение:
- Зашифрованную строку пароля

---

### Чтение метаданных соединения

Метод читает метаданные соединения, очищая пароль перед возвратом.

```javascript
async metadataItem(id)
```
Параметры:
- `id`: Уникальный идентификатор соединения

Возвращаемое значение:
- Объект метаданных соединения с пустым полем пароля

---

### Создание нового соединения

Метод создает новое соединение, предварительно зашифровывая пароль.

```javascript
async createMetadata(body)
```
Параметры:
- `body`: Объект с настройками нового соединения

Возвращаемое значение:
- Результат создания нового соединения

---

### Обновление существующих настроек соединения

Метод обновляет существующие настройки соединения, обрабатывая пароль (зашифровка или сохранение текущего значения).

```javascript
async updateMetadata(id, body)
```
Параметры:
- `id`: Уникальный идентификатор соединения
- `body`: Новые настройки соединения

Возвращаемое значение:
- Результат обновления соединения

---

### Частичное обновление метаданных

Метод частично обновляет метаданные соединения путем слияния новых данных с существующими.

```javascript
async patchMetadata(id, body)
```
Параметры:
- `id`: Уникальный идентификатор соединения
- `body`: Объект с частичными изменениями

Возвращаемое значение:
- Результат частичного обновления метаданных

---

### Тестирование соединения

Метод проверяет работоспособность указанного соединения, выполняя простой SQL-запрос.

```javascript
async test(id)
```
Параметры:
- `id`: Уникальный идентификатор соединения

Возвращаемое значение:
- `{result: boolean}`: Результат проверки соединения

---

### Логгинг базовых методов CRUD

Методы `create`, `read`, `update`, `delete` предназначены исключительно для логгинга операций над соединениями и выводят информацию в консоль.

---

## Использование модуля

Модуль должен использоваться в сервисном слое приложения для управления соединениями с внешними источниками данных. Его основные сценарии использования включают:

1. Настройку новых соединений через интерфейс администрирования
2. Управление существующими соединениями (редактирование, удаление)
3. Проверку работоспособности настроенных соединений
4. Интеграцию с системой шифрования для безопасной обработки конфиденциальной информации

---

## Важные замечания

- Пароли всегда должны быть зашифрованы перед сохранением в настройках соединения
- Метод тестирования соединения выполняет безопасный запрос SELECT 1 для проверки доступности источника данных
- Модуль использует библиотеку криптографии для безопасного хранения чувствительной информации
