# Документация модуля Enums

## Обзор

Модуль **Enums** предназначен для управления перечисляемыми типами данных в системе. Он расширяет функциональность базового класса `DefaultMetaObject` и предоставляет методы для создания, чтения, обновления и удаления метаданных перечисляемых типов.

## Структура модулей

Модуль имеет следующую структуру:

```
./__tests__/tests/Enums.service.test.js
./controllers/Enums.controller.js
./routers/Enums.router.js
./services/Enums.service.js
./package.json
```

## Основные компоненты

```javascript
constructor() {
```

## Интеграция с системой

Модуль интегрируется в систему через стандартный механизм загрузки сервисов и маршрутов, описанный в документации по архитектуре проекта. Для полноценной работы модуля необходимо наличие следующих компонентов:

# Документация модуля Values

## Обзор

Модуль **Values** предназначен для управления парами ключ-значение с возможностью отключения отдельных записей. Модуль наследуется от класса `DefaultMetaObject` и расширяет его функциональность специфичными полями и методами.

---

## Структура модуля

### Папки и файлы

- `services/Values.service.js`: Основной сервис модуля, содержащий основную логику обработки данных.

---

## Сервис ValuesService

Сервис `ValuesService` управляет структурой формы ввода данных и обеспечивает базовые операции с объектами типа "значений".

### Конструктор

Конструктор инициализирует базовый класс `DefaultMetaObject` и устанавливает уникальные идентификаторы для текущего компонента:

```javascript
constructor() {
    super(__dirname); // Указывает директорию текущего модуля
    
    const name = 'Values'; // Имя текущего компонента
    this.id = constants[name].id; // Уникальный ID компонента
    this.component = constants[name].component; // Компонент конфигурации
}
```

---

## Метод form()

Метод возвращает конфигурацию полей формы для создания новых объектов типа "значение":

```javascript
async form() {
    return {
        form: [
            {
                name: 'key',
                description: 'Ключ',
                type: 'STRING',
                template: 'Key',
            },
            {
                name: 'value',
                description: 'Значение',
                type: 'STRING',
                template: 'Value',
            },
            {
                name: 'onoff',
                description: 'Отключить',
                type: 'BOOL',
            },
        ],
    };
}
```

### Поля формы

| Поле      | Описание          | Тип данных |
|-----------|-------------------|------------|
| key       | Ключ              | STRING     |
| value     | Значение          | STRING     |
| onoff     | Отключить         | BOOL       |

---

## Интеграция с системой

Модуль интегрируется в систему через стандартный механизм загрузки сервисов, где:

- Используется базовая реализация метаданных через `DefaultMetaObject`
- Настраивается уникальный компонент через константы
- Предоставляется готовая форма для создания и редактирования объектов

---

## Возможности расширения

Модуль спроектирован таким образом, что вы можете легко расширить его функциональность путем добавления новых методов или изменения существующих. Например:

- Добавление метода для получения всех значений
- Реализация фильтрации отключенных значений
- Расширение функционала сохранения и обновления данных

Модуль **Values** представляет собой простой, но мощный инструмент для хранения пар ключ-значение с возможностью гибкого управления состоянием каждого элемента. Благодаря четкой структуре и интеграции с базовой архитектурой платформы, модуль легко поддерживается и масштабируется под конкретные потребности приложения.
