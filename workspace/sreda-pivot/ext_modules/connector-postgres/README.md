# Документация для модуля ConnectorPostgres

## Описание модуля

Модуль **ConnectorPostgres** предназначен для интеграции PostgreSQL в систему через стандартный интерфейс подключения коннекторов. Модуль реализует два основных метода: `loadConnectorsBefore` и `formAfter`, отвечающих за загрузку драйвера PostgreSQL и настройку интерфейса соответственно.

---

## Структура модуля

Модуль состоит из одного класса `ConnectorPostgres`, содержащего два асинхронных метода:

- `loadConnectorsBefore`: загружает драйвер PostgreSQL перед выполнением основной логики приложения.
- `formAfter`: настраивает отображение типа базы данных в форме конфигурации.

---

## Методы модуля

### Метод `loadConnectorsBefore`

Загружает драйвер PostgreSQL в список доступных коннекторов перед началом обработки запроса.

#### Параметры:
- `res`: объект ответа сервера
- `params`: параметры запроса

#### Возвращаемое значение:
Метод не возвращает значения, но изменяет параметр `params['ConnectorList']`, добавляя туда драйвер PostgreSQL.

---

### Метод `formAfter`

Настраивает форму конфигурации после формирования базовой структуры формы. Добавляет тип базы данных "POSTGRES" в соответствующий раздел формы.

#### Параметры:
- `res`: объект ответа сервера
- `params`: параметры запроса

#### Возвращаемое значение:
Возвращает объект ответа сервера с обновленной формой конфигурации.

---

## Использование модуля

Для использования модуля достаточно подключить его в нужное место вашего приложения и вызвать соответствующие методы в нужных местах жизненного цикла приложения.

Пример использования:

```javascript
const ConnectorPostgres = require('./ConnectorPostgres.service');
const connectorPostgres = new ConnectorPostgres();

async function initApp() {
    // Загрузка драйверов баз данных перед инициализацией приложения
    await connectorPostgres.loadConnectorsBefore({}, {});
    
    // Настройка формы конфигурации после ее создания
    const response = {};
    await connectorPostgres.formAfter(response, {});
}

initApp();
```

---

## Заключение

Модуль **ConnectorPostgres** обеспечивает простую и надежную интеграцию PostgreSQL в ваше приложение, предоставляя удобные точки расширения для настройки и управления конфигурацией базы данных.
