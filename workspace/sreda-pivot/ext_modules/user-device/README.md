# Документация модуля Device Service

## Описание модуля

Модуль `DeviceService` предназначен для управления устройствами пользователей в системе. Он обеспечивает функциональность добавления, удаления и получения устройств пользователя, а также применение настроек устройства.

## Основные методы

### addUserDevice(userId, device)
Добавляет устройство пользователя в хранилище.

**Параметры:**
- `userId`: Идентификатор пользователя (строка)
- `device`: Устройство для добавления (объект с полем `id`)

**Возвращаемое значение:** `{ result: boolean }` - результат операции.

---

### delUserDevice(userId, device)
Удаляет устройство пользователя из хранилища.

**Параметры:**
- `userId`: Идентификатор пользователя (строка)
- `device`: Устройство для удаления (объект с полем `id`)

**Возвращаемое значение:** Результат сохранения изменений в хранилище.

---

### getUserDevices(userId)
Получает список устройств пользователя.

**Параметр:**
- `userId`: Идентификатор пользователя (строка)

**Возвращаемое значение:** Массив устройств пользователя или пустой массив, если устройств нет.

---

### applyDevice(sourceDevice)
Применяет настройки устройства текущего пользователя.

**Параметр:**
- `sourceDevice`: Исходное устройство, чьи настройки применяются

**Возвращаемое значение:** Преобразованный массив настроек с новыми ключами.

## Внутренняя логика

Модуль использует класс `StoreModel` для взаимодействия с хранилищем данных. Ключи для хранения устройств имеют префикс `'user-devices'`. Для каждого пользователя создается отдельная запись в хранилище, содержащая объекты устройств.

Метод `applyDevice` работает следующим образом:
1. Получает текущие настройки источника устройства
2. Конвертирует строки настроек в объекты
3. Создает новые ключи настроек, используя текущее устройство пользователя
4. Сохраняет обновленные настройки в хранилище параллельно через промисы

## Зависимости

- `StoreModel`: Модель для взаимодействия с хранилищем данных
- `httpContext`: Контекст HTTP сессии для доступа к данным пользователя и устройству

## Примечания

- Все методы являются асинхронными и используют `async/await` синтаксис
- Модуль ожидает, что каждое устройство имеет уникальный идентификатор `id`
- Метод `addUserDevice` добавляет новое устройство только если оно еще не существует для данного пользователя
