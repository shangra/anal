## 1. Применение и функционал <a id="component-purpose" name="component-purpose"></a>

Модуль **page-cms** предназначен для обработки шаблонов и преобразование шаблонов в динамичный контент страниц. <br />
Страница - сущность, которая обращается к шаблонам и их параметрам, рендерит и вставляет параметры в шаблон, преобразовывает React-скрипты для frontend. <br />
Подробное описание параметров, их типов и того как они работают находится в модуле [template-cms](../template-cms/README.md).  <br />
Модуль `page-cms` поддерживает публичные и непубличные маршруты для редактирования параметров страниц, функционал для редактирования  <br />
информации о странице, ее местоположения, копирования и др. <br />

## 2. Пояснения к реализации <a id="implementation-explanation" name="implementation-explanation"></a>

Функционал страниц во многом сходится с функционалом модуля `template-cms`. Все указания в разделе [2. Пояснения к реализации](../template-cms/README.md) верны и для страниц.

## 3. Особенности применения <a id="apply-features" name="apply-features"></a>

В модуле `page-cms` есть аддоны, которые позволяют транспилировать React jsx-синтаксис в JavaScript вызовы React.createElement. <br />
Они необходимы для корректной обработки на frontend `вложенных компонентов`, которые позволяют удобно структуризировать компоненты и избежать коллизий имен. <br />
Например, MetadataUiKit > Input на frontend транспилируется в компонент ```MetadataUiKit__Input```. Для этого `backend` транспилирует jsx<br />
в JavaScript с применением `babel` и преобразует вызов `<React.MetadataUiKit.Input />` в синтаксис с нижними подчеркиваниями. <br />
