# Документация модуля MetaEye

## Обзор

Модуль **MetaEye** предназначен для интеграции просмотра сущностей метаданных в систему. Модуль расширяет функциональность платформы путем добавления кнопки для просмотра метаданных объектов через интерфейс компонента "MetaEye".

---

## Структура модулей

Модуль имеет следующую структуру:

```
./services/metaEye.service.js
```

---

## Сервис MetaEyeService

Сервис `MetaEyeService` наследуется от класса `Extensions`, предоставляющего базовые расширения функциональности системы.

### Методы сервиса

#### 1. formAfter()
Метод добавляет кнопку для просмотра метаданных в результат обработки формы.

##### Параметры метода:
- `innerResult`: текущий результат обработки формы
- `functionInput`: входные параметры функции

##### Логика работы:
1. Проверяется наличие массива кнопок в результате (`buttons`)
2. Создается новая кнопка с компонентом "MetaEye", содержащая информацию об объекте:
   - Имя кнопки: `"MetaEye"`
   - Компонент интерфейса: `"MetaEye"`
   - Пропсы компонента:
     - `id`: уникальный идентификатор объекта
     - `route`: маршрут компонента в нижнем регистре
     - `server`: имя сервера ESB из переменных окружения
     - `service`: путь к сервису метаданных
     - `title`: заголовок кнопки ("Просмотр сущности метаданных")
3. Добавляет созданную кнопку в массив кнопок результата

##### Возвращаемое значение:
Расширенный результат обработки формы с новой кнопкой.

---

#### 2. eye()
Метод возвращает метаданные объекта по его ID.

##### Параметры метода:
- `id`: строка, уникальный идентификатор объекта

##### Логика работы:
1. Запрашивает метаданные объекта через службу метаданных
2. Возврат результата запроса в формате `{ result: metadata }`

##### Возвращаемое значение:
Объект с полем `result`, содержащий метаданные запрошенного объекта.

---

## Интеграция и использование

Для использования функционала модуля необходимо подключить его в основной конфигурации системы и настроить соответствующие права доступа пользователей.

Компонент "MetaEye" должен быть зарегистрирован в системе визуальных компонентов для отображения кнопки в интерфейсе.

---

## Зависимости

Модуль зависит от следующих сервисов и классов:
- `Extensions.class`: базовый класс расширений системы
- `Costil.service`: вспомогательные сервисы (не используются непосредственно в текущем сервисе)
- `Metadata.service`: служба метаданных для получения информации об объектах

---

## Примечания

1. Для правильной работы компонента "MetaEye" необходимо убедиться, что сервер ESB настроен и доступен через переменные окружения (`sreda.env.ESB_NAME`)
2. Метод `formAfter()` автоматически интегрируется в процесс обработки форм благодаря наследованию от класса `Extensions`
3. Все взаимодействия с метаданными осуществляются через стандартизированный API службы метаданных
