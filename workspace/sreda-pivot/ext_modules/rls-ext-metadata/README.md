# Документация модуля RlsExtMetadataService

## Назначение модуля

Модуль `RlsExtMetadataService` предназначен для расширения функциональности управления метаданными в системе контроля доступа (Role Level Security Core - RLS Core). Модуль обеспечивает контроль прав доступа пользователей к метаданным, управление разрешениями и интеграцию с другими сервисами платформы.

---

## Основные функции модуля

### 1. Управление правами доступа к метаданным

Метод **createMetadataAfter**:
- Добавляет родительские разрешения к созданному элементу метаданных
- Применяет фильтрацию разрешений на основе групп текущего пользователя
- Автоматически добавляет разрешение администратора на просмотр элемента
- Возвращает результат создания элемента с настроенными разрешениями

### 2. Проверка прав перед созданием метаданных

Метод **addMetadataBefore**:
- Проверяет наличие прав на запись у владельца метаданных
- Генерирует ошибку, если необходимые права отсутствуют
- Позволяет предотвратить создание метаданных без достаточных полномочий

### 3. Расширение методов получения дочерних элементов

Метод **extendChildrenGetter**:
- Интегрирует функциональность получения дочерних элементов метаданных в модуль RLS Core
- Обеспечивает безопасную замену существующих методов
- Предотвращает конфликты имен методов через проверку биндинга

### 4. Настройка отображений таблиц

Метод **setMapping**:
- Устанавливает соответствие между названием таблицы ("metadata") и классом службы ("Metadata")
- Гарантирует правильное сопоставление сущностей в системе

---

## Использование модуля

Модуль должен использоваться совместно с модулем RLS Core для обеспечения комплексного управления правами доступа к метаданным. Типичный сценарий использования включает:

1. Создания новых записей метаданных с автоматическим назначением родительских разрешений
2. Проведения проверок прав доступа перед выполнением критических операций
3. Интеграции с существующими механизмами получения связанных данных

---

## Требования к интеграции

Для правильной работы модуля необходимы:

- Подключение модуля RLS Core
- Наличие валидной сессии пользователя с информацией о группах
- Корректное определение классов служб метаданных

---

## Исключительные ситуации

Модуль генерирует ошибки типа `ApiError.BadRequest` в следующих случаях:
- Попытка переопределить существующий метод получения дочерних элементов
- Отсутствие необходимых прав доступа при попытке создать метаданные

---

## Заключение

Модуль `RlsExtMetadataService` представляет собой важный компонент системы управления правами доступа, обеспечивающий безопасный и контролируемый доступ к метаданным. Его использование позволяет значительно повысить безопасность и управляемость приложений, работающих с чувствительными данными.
