# Документация модуля SessionSet

## Описание модуля

Модуль **SessionSet** предназначен для управления сессиями пользователей через HTTP-контекст. Основная цель модуля - предоставление простого интерфейса для доступа к данным сессии текущего пользователя.

---

## Структура модуля

Модуль имеет следующую файловую структуру:

```
./services/SessionSet.service.js
```

---

## Сервис SessionSet

Сервис предоставляет один метод для получения данных сессии текущего пользователя.

### Класс SessionSetService

Класс наследуется от базового класса сервисов платформы и импортирует библиотеку `httpContext` для взаимодействия с HTTP-контекстом.

#### Метод get()

Метод возвращает текущие данные сессии пользователя.

- **Возвращаемое значение:** Объект с данными сессии текущего пользователя
- **Тип возврата:** Object

Пример использования метода:

```javascript
const sessionSetService = new SessionSetService();
const sessionData = await sessionSetService.get();
console.log(sessionData); // Выведет объект с данными сессии
```

---

## Интеграция с системой

Модуль интегрируется с платформой через стандартный механизм загрузки сервисов. Для использования сервиса достаточно создать экземпляр класса `SessionSetService` и вызвать необходимый метод.

---

## Особенности реализации

1. Модуль использует встроенную систему HTTP-контекста платформы для безопасного доступа к данным сессии
2. Реализация минималистична и предназначена исключительно для чтения данных сессии
3. Не требует внешних зависимостей кроме базовой инфраструктуры платформы

---

## Тестирование

Тестовый пример для проверки функциональности сервиса:

```javascript
const SessionSetService = require('./services/SessionSet.service');

test('Проверка получения данных сессии', async () => {
    const service = new SessionSetService();
    const sessionData = await service.get();
    
    // Проверка наличия ожидаемых полей в объекте сессии
    expect(typeof sessionData).toEqual('object');
    expect(Object.keys(sessionData)).toContain('userId');
    expect(Object.keys(sessionData)).toContain('sessionToken');
});
```
