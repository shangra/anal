# Документация модуля MetaEye

Данный модуль предназначен для работы с сущностями метаданных и предоставляет возможность просмотра этих сущностей через интерфейс компонента «MetaMatrix». Модуль расширяет функциональность основной платформы за счет интеграции с системой метаданных.

## Структура модулей

### Папки и файлы

- **metaMatrix.service.js**: Основной сервис модуля, содержащий реализацию методов для формирования кнопок интерфейса и получения метаданных.

### Сервисы

#### Класс MetaEyeService

Этот класс наследуется от базового класса `Extensions`, который обеспечивает доступ к системным функциям расширения ядра платформы.

##### Методы

- **formAfter** (`async`)

  Этот метод вызывается после выполнения основного функционала и добавляет кнопку «MetaMatrix» в пользовательский интерфейс. Кнопка отображает сущность метаданных при нажатии.

  Параметры метода:
  - `innerResult`: результат выполнения предыдущего этапа обработки запроса.
  - `functionInput`: информация о текущем запросе, включая идентификатор сущности (`id`) и другие параметры.

  Возвращаемое значение:
  - Обновленный объект результата с добавленной кнопкой.

- **matrix** (`async`)

  Метод получает метаданные конкретной сущности по ее идентификатору и возвращает эти данные пользователю.

  Параметр метода:
  - `id`: строка, уникальный идентификатор сущности.

  Возвращаемое значение:
  - Объект с результатом, включающий полученные метаданные.

---

## Пример использования

Предположим, у вас есть сущность с идентификатором `"entity_123"` и вы хотите получить её метаданные:

```javascript
const metaEyeService = new MetaEyeService();

(async () => {
    const metadata = await metaEyeService.matrix('entity_123');
    console.log(metadata); // Выводит метаданные сущности entity_123
})();
```

## Интеграция с платформой

Модуль интегрируется с основной платформой путем добавления кнопки в интерфейс пользователя. При клике на эту кнопку открывается компонент «MetaMatrix», который показывает подробную информацию о выбранной сущности метаданных.
