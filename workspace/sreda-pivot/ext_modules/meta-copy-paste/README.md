# Модуль MetaCopyPaste

Данный модуль предоставляет функциональность копирования и вставки объектов метаданных. Он включает в себя сервисные методы для выполнения этих действий, а также обработку изменений значений при вставке скопированных данных.

## Структура модулей

### services/metaCopyPaste.service.js

Этот файл содержит класс `MetaCopyPasteService`, который реализует основные методы для работы с объектами метаданных.

#### Методы класса

- **formAfter**: Добавляет кнопки для копирования и вставки данных объекта метаданных.
- **copy**: Копирует данные объекта метаданных по заданному идентификатору.
- **changeValues**: Рекурсивно изменяет значения в объекте согласно переданным заменяющим значениям.
- **pasteChildren**: Вставляет дочерние элементы объекта метаданных рекурсивно.
- **paste**: Основной метод для вставки скопированного объекта метаданных.
- **_paste**: Внутренний метод для реализации транзакции вставки объекта метаданных.

### Пример использования

```javascript
const MetaCopyPasteService = require('./metaCopyPaste.service');
const metaCopyPasteService = new MetaCopyPasteService();

async function main() {
    const metadataId = 'some-id'; // ID объекта метаданных
    const copiedData = await metaCopyPasteService.copy(metadataId); // Копируем данные
    console.log(copiedData);

    const pastedData = await metaCopyPasteService.paste(metadataId, copiedData); // Вставляем данные
    console.log(pastedData);
}

main().catch(console.error);
```

## Описание методов

### formAfter

Добавляет две кнопки (`MetaCopy` и `MetaPaste`) в интерфейс пользователя для выполнения операций копирования и вставки данных объекта метаданных.

**Параметры:**
- `innerResult`: Результат предыдущей обработки формы.
- `functionInput`: Входные параметры функции.

**Возвращаемое значение:** Объект с обновленным списком кнопок.

---

### copy

Копирует данные объекта метаданных по указанному идентификатору.

**Параметр:**
- `id`: Идентификатор объекта метаданных.

**Возвращаемое значение:** Объект с результатом копирования.

---

### changeValues

Рекурсивно меняет значения в объекте согласно переданным заменяющим значениям.

**Параметры:**
- `value`: Исходное значение.
- `replacedValues`: Объект с заменяющими значениями.

**Возвращаемое значение:** Преобразованное значение.

---

### pasteChildren

Вставляет дочерние элементы объекта метаданных рекурсивно.

**Параметры:**
- `newOwner`: Новый владелец элементов.
- `items`: Массив дочерних элементов.
- `pasted`: Объект со вставленными элементами.

---

### paste

Основной метод для вставки скопированного объекта метаданных.

**Параметры:**
- `id`: Идентификатор объекта метаданных.
- `body`: Тело запроса с результатами копирования.

**Возвращаемое значение:** Объект с результатом вставки.

---

### _paste

Внутренний метод для реализации транзакции вставки объекта метаданных.

**Параметры:**
- `id`: Идентификатор объекта метаданных.
- `body`: Тело запроса с результатами копирования.

**Возвращаемое значение:** Объект с результатом вставки.

## Заключение

Модуль `MetaCopyPaste` обеспечивает гибкую систему для копирования и вставки объектов метаданных, позволяя пользователям легко управлять этими операциями через пользовательский интерфейс.
