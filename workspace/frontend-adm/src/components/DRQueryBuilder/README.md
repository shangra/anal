## 1. Применение и функционал <a id="component-purpose" name="component-purpose"></a>

Компонент **DRQueryBuilder** предназначен для формирования WHERE-условий запроса в БД <br />

**Правило** - унарная операция <br/>
**Группа** - операция, состоящая из правил. Она задает логические отношения между операциями

Доступные операции правил

1. равно | $eq | =
2. не равно | $ne | !=
3. больше чем | $gt | >
4. больше или равно | $gte | >=
5. меньше | $lt | <
6. меньше или равно | $lte | <=

Доступные операции групп

1. И
2. ИЛИ

## 2. Пояснения к реализации <a id="implementation-explanation" name="implementation-explanation"></a>

Стейт представляет рекурсивную структуру. Для поиска и мутации в которой используется ключ, который формируется путем слиянием родителя с ребенком (иерархично). Например: есть следующий объект: {name: { or: [{ eq: "Иван" }, {eq: "Никита"} ] } }. Путь до свойства со значением Иван будет "name.or.[0].eq";

## 3. Особенности применения <a id="apply-features" name="apply-features"></a>
