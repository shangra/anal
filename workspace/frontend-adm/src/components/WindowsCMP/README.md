# Документация модуля интерфейсов (`interfaces`)

Данный модуль содержит набор типов и интерфейсов, используемых для описания состояния и поведения различных компонентов пользовательского интерфейса приложения. В частности, он определяет типы и интерфейсы для работы с окнами и панелями.

## Типы и перечисления

### Перечисление позиций меню (`MENU_POSITION`)
Перечисляет возможные позиции размещения элементов меню относительно основного окна.

| Значение      | Описание                     |
|---------------|------------------------------|
| `window`      | Элемент отображается внутри окна |
| `left`        | Элемент слева от окна          |
| `right`       | Элемент справа от окна         |
| `top`         | Элемент сверху окна            |
| `bottom`      | Элемент снизу окна              |

Тип: `MenuPosition`.

---

### Перечисление положений панелей (`PanelPosition`)
Определяет возможные положения панелей относительно главного окна.

| Значение      | Описание                   |
|---------------|----------------------------|
| `left`        | Панель расположена слева    |
| `right`       | Панель расположена справа   |
| `bottom`      | Панель расположена внизу    |

Тип: `PanelPosition`.

---

## Интерфейсы

### Интерфейс состояния окна (`IWindow`)
Интерфейс описывает состояние отдельного окна в приложении.

#### Поля:

- **`key`:** Уникальный идентификатор окна (строка).
- **`title`:** Заголовок окна (строка).
- **`style?`:** Стили оформления окна (опциональные свойства CSS).
- **`content`:** Содержимое окна (React-компонент или узел).
- **`zIndex?`:** Индекс слоя окна (по умолчанию — автоматически определяется системой).
- **`close?`:** Признак того, можно ли закрыть окно (булево значение; опционально).
- **`callback?`:** Функция обратного вызова при закрытии окна (опциональна).
- **`portal?`:** Контейнер DOM-элемента, куда рендерится окно (опционален).
- **`position?`:** Положение окна (тип `PanelPosition`, опционально).
- **`isMinimized?`:** Признак минимизации окна (булевое значение, опционально).
- **`type?`:** Тип окна («setting» или «tab», опционально).
- **`onClose?`:** Обработчик события закрытия окна (функция без аргументов, опциональна).

---

### Интерфейс состояния боковой панели (`ISidebarState`)
Описывает текущее состояние боковой панели.

#### Поля:

- **`isOpen`:** Показатель открытости панели (булев тип).
- **`tabs`:** Запись всех открытых вкладок в виде объектов типа `IWindow`, где ключ — уникальный идентификатор вкладки.
- **`activeTabId`:** Идентификатор активной вкладки (строка).

---

# Модуль Utils

Данный модуль содержит вспомогательные функции, которые могут использоваться в различных частях приложения. Он экспортирует две основные функции: `isEmptySidebar` и `capitalizeFirstLetter`.

## Экспортируемые функции

### `isEmptySidebar(sidebar)`

Проверяет, пуст ли боковой блок (`sidebar`), проверяя количество ключей в объекте `tabs`. Если количество ключей равно нулю, функция возвращает `true`, иначе — `false`.

#### Параметры:
- **sidebar**: объект типа `ISidebarState`, представляющий состояние бокового блока.

#### Возвращаемое значение:
- Логическое значение (`boolean`) — `true`, если боковая панель пуста; `false` в противном случае.

---

### `capitalizeFirstLetter(str)`

Преобразует первую букву строки в верхний регистр, оставляя остальные буквы без изменений.

#### Параметры:
- **str**: строка, первая буква которой должна быть преобразована в верхний регистр.

#### Возвращаемое значение:
- Строка с первой заглавной буквой.

---

## Пример использования

```typescript
import { isEmptySidebar, capitalizeFirstLetter } from './utils';

const sidebar: ISidebarState = { tabs: {} };
console.log(isEmptySidebar(sidebar)); // true

const str = "hello world";
console.log(capitalizeFirstLetter(str)); // Hello world
```

Эти функции можно использовать как часть общего набора утилит для работы со строками и состояниями интерфейса.
