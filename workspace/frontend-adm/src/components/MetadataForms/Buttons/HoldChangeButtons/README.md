Модуль HoldChangeButtons

1. Применение и функционал
Кнопки для плавного изменения числового значения при удержании мыши.

2. Пояснения к реализации
Хук useHoldToChangeCounter при нажатии сразу меняет значение, затем через delayBeforeHold запускает интервал с частотой holdInterval.

3. Особенности применения
step – шаг изменения (в т.ч. дробный, с корректным округлением).

onClickRange – срабатывает при каждом клике, независимо от onValueChange.
