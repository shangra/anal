## 1. Применение и функционал <a id="component-purpose" name="component-purpose"></a>

Компонент **DateTimeProcessor** предназначен для обработки и преобразования формата даты и времени в нужный. <br />
Представляет собой набор утилит.

## 2. Пояснения к реализации <a id="implementation-explanation" name="implementation-explanation"></a>

Для реализации использовалась библиотека `dayjs`. В функцию преобразования передается шаблон выходного формата даты и времени.

## 3. Особенности применения <a id="apply-features" name="apply-features"></a>

Полный формат - `DD.MM.YYYY[,] HH:mm:ss.SSS`:

1) `DD` - день;
2) `MM` - месяц;
3) `YYYY` - год;
4) `HH` - часы;
5) `mm` - минуты;
6) `ss` - секунды;
7) `SSS` - миллисекунды.

Можно устанавливать символы разделители (например запятая в примере `[,]`). Если нужно изменить формат, например, не указывать <br />
миллисекунды, шаблон должен быть указан без миллисекунд - `DD.MM.YYYY[,] HH:mm:ss`.
